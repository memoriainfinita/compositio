# compositio guide

How to use compositio for what you want to do with it. Each page is a short walk through; the [README](../../README.md) lists everything the app does.

| I want to… | Page |
|---|---|
| Open it and process my first file | [Getting started](getting-started.md) |
| Trim, normalize and convert a batch of files | [Batches](batches.md) |
| Make one continuous mix for a show | [Mixing](mixing.md) |
| Keep my work and move it to another device | [Montages](montages.md) |
| Use it on a phone or install it as an app | [Phone and install](phone.md) |
| Know what each browser can and cannot do | [Browsers](browsers.md) |

Everything happens in the browser: files are read where they are and never uploaded. Results are new files in the downloads; the originals are never touched. compositio is in English and Spanish and follows the language of the browser.
